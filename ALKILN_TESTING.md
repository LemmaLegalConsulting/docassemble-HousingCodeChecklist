The existing maximalist_path.feature completes the housing-code court-help journey, verifies the download question, and downloads the resulting housing documents. Its wait allows asynchronous document assembly after the waiting screen; the final question assertion and downloads remain enabled.

The isolated workflow uses the fleet-tested docassemble 1.10.7 image pinned by registry digest. The package used to ship a `docassemble/__init__.py` that imported pkg_resources, which setuptools 82 removed; docassemble 1.10.7 itself requires setuptools 83.0.0, and clean-server Celery logs confirmed the missing import prevented worker startup and custom datatype registration. Pinning setuptools only fought the platform's own pin, so the file is gone instead: docassemble and its AssemblyLine dependencies use the implicit `docassemble` namespace package, and this package now does too, with no setuptools runtime dependency. The feedback dependency is pinned to public immutable commit `2601e16be3ed0baca440bd3b2b78c0890e00a22c`, before an upstream Markdown-renderer change introduced an import that the installed platform no longer exports. This preserves the feedback integration without the import blocker. A full isolated browser rerun is pending, and the PR remains draft until it passes. Server and worker diagnostics are printed on failure.
